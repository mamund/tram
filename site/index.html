TRAM is a declarative API testing tool. Describe what an API should do, execute HTTP interactions, evaluate assertions, and preserve the evidence of what happened.

HOW IT WORKS

From expectations to evidence.

TRAM keeps the behavioral claim visible throughout the test.

01

Define

Describe requests and expected behavior in a JSON manifest.

02

Execute

Run the manifest against an HTTP API from the CLI or a Node.js application.

03

Evaluate

Check responses against the assertions you declared.

04

Examine

Use the resulting reports and transcripts to understand the outcome.

TWO WAYS TO RUN TRAM

Use TRAM from the command line or Node.js.

Run the same assertion manifest through the CLI or embed TRAM in an application.

COMMAND LINECLI
RUN A MANIFEST
tram api-tests.json

Execute assertions and inspect the results in your terminal.

NODE.JS APICOMMONJS
RUN PROGRAMMATICALLY
const tram = require('@mamund/tram');

async function main() {
  const manifest = tram.loadManifest('./api-tests.json');
  const result = await tram.run(manifest);
  console.log(result.summary);
}

main().catch(console.error);

WHY TRAM

Generated code still needs verification.

When implementation becomes easier to produce, deciding what to verify becomes more important.

TRAM supports evidence-based testing: identify observable behaviors, express them as assertions, and retain evidence of the results.

One useful starting point is to distinguish behaviors that are explicit in a story, required for it to work, or implied by its context.
